# Glossário

| Termo | Significado |
|---|---|
| AB | etapa As Built no código CONDER |
| AF / AGF | água fria (AGF é o código CONDER) |
| As built | o que foi executado na obra; vale sobre o projeto |
| BL | boca de lobo |
| CA | caixa de areia |
| CDE | ambiente comum de dados das pranchas vigentes |
| CE / CS | cota de entrada / saída do tubo na caixa |
| CF | cota de fundo |
| CG | caixa de gordura |
| CI | caixa de inspeção |
| CONDER | órgão que aprova o projeto |
| CT | cota de tampa |
| DE / DN | diâmetro externo / nominal |
| DRE | drenagem |
| ELE | elétrica (EL é código antigo, não usar) |
| ESG | esgoto |
| ETIB | escola de tempo integral (as escolas do contrato) |
| Federado único | um IFC4 da escola inteira (cap. 06) |
| GI | geratriz inferior do tubo |
| HID | hidrante |
| IMP | implantação (RVT ou setor da prancha) |
| PCI | incêndio (hidrante e SDAI); IN/INC é código antigo |
| PEAD | polietileno de alta densidade (eletroduto e hidrante enterrados, flexível) |
| preclash | motor de modelagem e pré-compatibilização sem Revit |
| PV | poço de visita |
| SDAI | sistema de detecção e alarme de incêndio |
| SIT / TOP / TER / PAV | planta de situação / topografia / terraplenagem / pavimentação |
| TIN | malha triangulada do terreno |
| UTM SIRGAS 2000 | sistema de coordenadas (EPSG:31984, zona 24S) |
